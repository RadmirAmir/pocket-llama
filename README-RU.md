# Pocket 0.8.0 — подготовка дистрибуции

**[Скачать публичный APK](https://github.com/RadmirAmir/pocket-llama/releases/download/v0.8.0-rc.1/PocketLlama-0.8.0-community-arm64.apk)** · [Страница релиза, AAB и SHA-256](https://github.com/RadmirAmir/pocket-llama/releases/tag/v0.8.0-rc.1). Android 10+, ARM64. Этот preview устанавливается рядом с личным приложением.

В настройках появился каталог трёх небольших Qwen 3.5: рекомендация по памяти телефона, загрузка с докачкой, проверка SHA-256, выбор безопасного CPU-профиля. Собственный GGUF по-прежнему можно импортировать.

**Личное обновление** `PocketLlama-0.8.0-personal-update-arm64.apk` устанавливается поверх 0.7.3 с прежней подписью и пакетом `dev.pocketllama.memoryfix`. GigaAM и PaddleOCR встроены и работают без загрузок. Поддержка прежней Surya сохранена: установленные веса используются повторно, на чистой установке её большие VLM-веса скачиваются отдельно. Полностью автономный личный вариант с Surya можно собрать по инструкции; он занимает около 1,52 ГБ.

**Публичный предварительный вариант** использует отдельный пакет `dev.pocketllama` и устанавливается рядом. В нём встроены GigaAM v3 INT8, VAD, определение спикеров и PaddleOCR. Публичный профиль исключает веса Surya и некоммерческий детектор до получения прав на распространение. Не удаляйте личное приложение для проверки этого варианта: автоматического переноса защищённого хранилища между пакетами нет.

Для Google Play подготовлены AAB и устанавливаемые вместе с приложением пакеты речевых/OCR-моделей. Исходный комплект для GitHub не содержит ключей подписи, весов, результатов сборки и кешей. Публикация ещё требует данных издателя, производственной подписи, проверки на телефонах и аккаунта Play Console.
