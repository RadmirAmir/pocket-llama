Video import runtime — Pocket 0.6.0

The APK embeds public CPython and QuickJS binaries supplied by
io.github.junkfood02.youtubedl-android:library:0.18.1, plus the official yt-dlp
2026.08.19 release zipapp (including yt-dlp-ejs). No wrapper classes.jar is used.
The Python package ZIP is normalized to resolve Unix symlinks to regular files.
The app-specific launcher replaces the upstream QuickJS temporary JS-file
transport with a Linux anonymous memfd and uses a private process group.

Upstream runtime build/source:
https://github.com/yausername/youtubedl-android/tree/0.18.1
https://github.com/termux/termux-packages
https://github.com/python/cpython/tree/3.12
https://github.com/bellard/quickjs
https://github.com/yt-dlp/yt-dlp/tree/2026.08.19
https://github.com/yt-dlp/ejs
