# Pocket Llama 0.13.2 RC.1

Интернет-поиск теперь полностью работает под капотом. Убраны открывающееся окно
с выдачей, браузерная сессия и переход к CAPTCHA. Новости читаются через
встроенный SearXNG из RSS; обычные запросы используют RSS и публичный API.
В чате остаются действия помощника и ссылки на найденные источники.

Агентный цикл продолжает работу после каждого результата: модель выбирает
инструмент, читает ответ, уточняет запрос или завершает поиск. Цикл нативный,
по схеме action/result, использованной в Pi. Для телефона сохранены короткие
решения: до 1,024 входных и 96 выходных токенов; максимум три вызова
инструментов и пять решений. В итоговый контекст попадает до шести фрагментов
без повторяющихся веб-ссылок.

Локальные заметки не считаются подтверждением интернет-поиска. Ошибка веб-поиска
больше не маскируется под нехватку контекста после чтения заметок. Если агент
решил обойтись без инструментов, ответ сразу использует исходный запрос.
Поиск только по личным материалам исключает веб-инструмент для этого запроса.

Это обновление основного приложения dev.pocketllama, код версии 35, с прежней
подписью. CPU/Vulkan, диктофон, ASR, OCR, видео, заметки, RAG и шифрование
сохранены. Проверки и ограничения описаны в [validation](VALIDATION-0.13.2.md).
