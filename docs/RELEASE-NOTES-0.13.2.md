# Pocket Llama 0.13.2 RC.1

Исправлены инструкции агентного цикла: помощник больше не получает сообщение
о выполненном интернет-поиске, когда инструмент не запускался или работал только
с личной базой знаний. При отказе от инструментов сразу используется исходный
запрос, без лишнего подбора контекста.

Если обязательный веб-поиск завершился ошибкой после чтения заметок, приложение
показывает настоящую причину сбоя. Такая ошибка больше не называется нехваткой
контекста. Когда веб-поиск необязателен, ответ по найденным личным данным остаётся
доступен без заявления, что актуальные факты проверены в интернете.

Сохранены браузерный поиск с ручным подтверждением CAPTCHA, встроенный SearXNG
для новостей, максимум два вызова инструментов и все функции основного
приложения `dev.pocketllama`. Код версии 35, прежняя подпись обновления.

See [validation](VALIDATION-0.13.2.md). The production HTTP/SSE agent tests now
cover 63 assertions, including no-tool, local-only and mixed failed-web cases.
