# Pocket Llama 0.13.4 RC.1

Исправлены итоги видео, в которых модель выдавала названия тем вместо содержания.

- Локальная модель выбирает важные высказывания; приложение показывает их текст из расшифровки с привязанными исходными репликами. Суммы, даты и оговорки сохраняются в исходной формулировке и на языке записи.
- Выбор охватывает разные части ролика. Маленькая модель не может заполнить все итоги только началом видео.
- Ответ модели ограничен коротким списком номеров и 192 токенами. Сохраняются ограниченный контекст, отмена и продолжение обработки длинных записей.
- У старых итогов появилась кнопка «Обновить итоги». Повторно скачивать или расшифровывать видео не нужно.

После установки откройте видео → «Итоги» → «Обновить итоги» (или «Создать заново»).
Это обновление основного приложения `dev.pocketllama`, с прежней подписью.
