# Pocket Llama 0.13.3 RC.1

Исправлены итоги видео, в которых вместо содержания появлялись названия вроде
«Фрагмент про…» и повторяющиеся номера ссылок. Модель получает явное задание
изложить конкретные утверждения, суммы, даты и оговорки. Названия фрагментов,
вложенные заголовки и пункты, состоящие только из ссылок, не сохраняются как
готовый конспект: доступна одна попытка исправить содержание в пределах
существующего лимита генерации.

В итогах видео может быть до пяти разных ключевых тезисов; пустые разделы
скрыты. Повторяющиеся ссылки на одну реплику показываются один раз.
Нажатие на источник открывает нужную реплику в расшифровке без модального окна,
в том числе за пределами первых 100 реплик.

Для уже сохранённого неудачного результата нажмите **«Создать заново»** под
итогами. Конспект будет построен по исходной расшифровке с новым запросом к
модели; старые промежуточные заметки видео не будут использованы. Записывать
или загружать видео заново не требуется.

Это обновление основного dev.pocketllama, код версии 36, с прежней подписью.
Проверки и ограничения — в [validation](VALIDATION-0.13.3.md).
