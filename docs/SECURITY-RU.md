# Приватность и защита в Pocket

[← Pocket](../README-RU.md) · [English](SECURITY.md)

Здесь описано устройство публичной предварительной версии 0.9.0. Это техническое объяснение продукта; независимый аудит безопасности не проводился. Окончательная юридическая политика издателя оформляется отдельно.

## Что остаётся на телефоне

Запись, распознавание речи GigaAM (RU) / Moonshine Streaming Medium (EN), разделение спикеров, PaddleOCR, чат с локальной LLM и конспекты выполняются на Android-устройстве. Нет облачного аккаунта для ИИ, рекламных SDK, автоматической аналитики и автоматической отправки отчётов о сбоях. Записи, сканы, расшифровки и переписка автоматически никуда не загружаются.

Речевые и OCR-модели встроены в публичный APK. Для чата и конспектов один раз скачайте или импортируйте совместимую языковую модель. После подготовки основные функции работают в авиарежиме.

## Защита сохранённого и доступа

| Что | Как защищено |
| --- | --- |
| Аудиофайлы | Аутентифицированное шифрование блоками AES-256-GCM; отдельный ключ файла защищён ключом хранилища |
| Фотографии, записи документов, переписка и личные файлы приложения | Зашифрованные локальные файлы AES-GCM |
| Расшифровки и метаданные диктофона | База SQLCipher с защищённым секретом базы |
| Личные заметки, заголовки и поля поиска | Отдельная база SQLCipher под тем же защищённым секретом хранилища; внешнего поискового сервиса нет |
| Ключи | Android Keystore; аппаратная защита зависит от телефона |
| Вход | Шестизначный PIN с задержками после ошибок; PIN — отдельный контроль доступа, а не сам ключ шифрования |
| Уход в фон | Приложение блокируется; активная служба записи или обработки может продолжать работу |
| Захват экрана | Флаг Android `FLAG_SECURE` на экранах приложения |
| Резервное копирование Android | Отключено в манифесте и правилах бэкапа/извлечения |

Во время работы приложение расшифровывает необходимые данные. Шифрование хранения не защищает уже экспортированный файл, скопированный в другое приложение текст или устройство со скомпрометированной системой. Обещания независимой сертификации или абсолютной неуязвимости здесь нет.

## Когда используется сеть

| Ваше действие | Что происходит |
| --- | --- |
| Обновление каталога или загрузка модели | Хостинг получает запрос на каталог/файл. Личные записи, сканы и переписка в эту загрузку не включаются |
| Импорт видео по ссылке | Приложение обращается к видеосервису за выбранным медиа; полученный звук обрабатывается локально |
| Открытие источника модели или внешней ссылки на видео | Браузер либо выбранное приложение обращается к сайту |
| Экспорт, отправка или копирование | Выбранное место назначения получает выбранное вами содержимое; дальше действуют его правила хранения и сети |
| Включение дополнительного LAN API | Клиенты сети с API-токеном получают доступ к HTTP API выбранной модели. TLS нет. По умолчанию выключено; база записей и документов не открывается |
| Добровольное обращение о содержимом | Только после нажатия отправки передаются просмотренный фрагмент ответа, комментарий, категория и версия приложения. Остальная переписка, записи и документы автоматически не прикладываются |

**Сервер обращений в публичном preview не настроен.** В исходниках есть возможность настроить его для издателя. Отправка требует HTTPS, перенаправления не выполняются. После ошибки обращение не ставится в скрытую очередь на будущую отправку. При включении сервера издатель должен указать получателя и сроки хранения.

Загрузки моделей проверяются по SHA-256 и подписанному каталогу. Это проверка соответствия файла ожидаемым байтам, а не гарантия правильности или безопасности ответов модели.

## Хранилище связано с этой установкой

Нет облачной синхронизации, облачной копии хранилища и восстановления PIN через сервер. Удаление приложения или очистка данных лишает доступа к зашифрованному хранилищу. Системный бэкап выключен. Экспортируйте важное заранее и отдельно защищайте экспортированные копии.

У личного и публичного пакетов отдельные данные и ключи. Установка публичного APK автоматически не переносит прежнее хранилище. Для обновления поверх должны совпадать пакет и подпись.
