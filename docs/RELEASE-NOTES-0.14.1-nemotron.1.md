# Pocket Llama 0.14.1 — interface update

This update refines the recordings, scanner, notes and chat interfaces while keeping the existing local models and encrypted storage.

- The recording action has its own space above navigation and no longer covers content on smaller screens or in landscape.
- Secondary text is easier to read, and playback, chat and scanner controls have larger touch areas.
- OCR progress follows the selected theme. Surya OCR 2, page layout and tables remain available.
- Includes the Nemotron 3 diarization candidate from 0.14.0.

This is a test release. Install it over the existing community build without deleting the application. The release is not a physical-device performance or accuracy certification.
